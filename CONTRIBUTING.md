# Contributing / コントリビューション

不具合は再現操作と環境、必要なログを添えてIssueへ。PRは目的、変更、検証結果を説明し、`make test` と `make release` を通してください。音声タイミングに影響する変更は実機検証も記録してください。秘密情報や個人情報をログに含めないでください。

Report bugs with reproduction steps, environment and relevant logs. Explain the purpose, changes and validation in pull requests. Run `make test` and `make release`; include hardware validation for changes affecting audio timing. Remove secrets and personal information from logs.
